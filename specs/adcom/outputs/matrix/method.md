# How the conformance matrix is read

Generated by `npm run matrix`; don't edit it by hand. It is [`matrix/method.yaml`](../../../../matrix/method.yaml), the reviewed method, rendered; the grid it grades is [`matrix.md`](matrix.md), and every cell there links a section of this file.

## What a cell may be about

### Coverage of codes

Which codes of this list does the library declare, and which values does it declare that this list has no code for?

**Read from.** The enum this library pairs with the list in specs/<spec>/outputs/enum-drift/sources.yaml, read from the library's pinned evidence: every value's number against every code the registry's own IR gives the list, and against the vendor range the list reserves where it reserves one, since a number in that range is no code of the list and no value the library invented. One reading for every row: a stricter rule that binds one library, as this repository's target rules bind its own proto, is that target's gate to enforce and no part of this dimension, or our row would be graded by a rule no other row is held to.

**Where the evidence cannot answer.** declares no enum for this list; the evidence read for it holds none

### Declared value type

What integer type does the library declare for this list's codes, and can that type hold every code the list has?

**Read from.** The type written on the enum's own declaration in the library's pinned evidence -- a Go constant's type, as `int8` -- read against the list's codes and against the vendor range it reserves, since a type that holds every code may still be too narrow for the range. Where the declaration states no type, that is the answer, and `absent` is how the cell says so.

**Where the evidence cannot answer.** declares none; the file states no width

## Where a cell's evidence came from

- `static`: The cell was read from a pinned snapshot of the library's own source, or from the files one of this repository's targets writes, and never from running either. It says what the source declares. It says nothing about what the library does with a payload at run time, because no evidence here has been gathered about that, and a reader who needs that answer is owed the absence of it rather than an inference from a declaration.

## The links every cell carries

- `list`: The list the cell is about, on this site's type map at the list's vocabulary, so a reader sees the codes the cell was read against rather than taking the cell's word for what they are. Where the specification tabulates no codes for the list, there is no vocabulary and so no address on the map, and the link is the map itself with no type open: a cell whose answer is that there is nothing there still says where the looking happened, which is what makes that answer checkable too.
- `library`: The library's own source at its pin: the line the enum or the value is declared on, or, where it declares none, the pinned folder the reader read. A cell whose answer is that there is nothing there still says where the looking happened, which is what makes that answer checkable too.
- `specification`: The line of the specification the list's code comes from, reached through the registry's own IR element, so the far end of every cell is the text and not this repository's reading of it.

## No value stands for several cells

No value anywhere in the matrix stands for more than one cell. Not a total over a row or a column; not a percentage; not a count of cells in any state, a count of the full ones included; not a count against a denominator; not an order by anything but the key `order` names for that axis; not a colour or a bar whose steps put one cell above another; and not a sentence that sums a library up in place of a cell that holds something. It binds every document a run writes and every page that renders one.

**Why.** A matrix that scores libraries invites a reader to rank them, and a rank is the one thing this matrix has no evidence for: a cell is read from one list and one declaration, and nothing here measures how much any list matters to anybody. The reader this exists for arrives holding one list and wants to know what each library does with that list, and that reader is served by the row they came for. A number that let them skip reading it would be a number nobody here can support, and it would be the number everyone quoted. There is no threshold at which an aggregate becomes supportable, so there is none at all, which also leaves no judgment call for a later author to make differently.

**Ordered by.** The libraries ascending by `id`; the lists in the registry's own order.

**Refused forms.**

- `total`: A sum over a library's row or over a list's column, of cells or of anything inside them.
- `percentage`: A share of cells, or of codes, written as a percentage or as a decimal fraction of the whole.
- `count`: A count of cells in any state, a count of the full ones included, since a count orders libraries as surely as a total does.
- `ratio`: A count written against a denominator, a cell count over the cells there could have been, in a document or in a sentence.
- `order`: An order of libraries or of lists by anything but the key `order` names for that axis, which is an aggregate written as a sequence.
- `scale`: A colour, a bar, a star, or any symbol whose steps place one cell above another rather than naming what that cell holds.
- `summary`: A sentence that says what a library is like across its cells, in place of what one of its cells holds.

**Property names no emitted document may carry.** `count`, `coverage`, `grade`, `percent`, `rank`, `score`, `summary`, `totals`.

## A cell holds what the evidence holds

A cell holds what the library's own pinned evidence holds, and nothing a reader could not find there. Where that evidence does not answer the dimension's question, the cell says so in the dimension's `absent` words and links where the looking happened. It is never filled in from the language's defaults, from another library's declaration, or from what this repository takes the answer to be.

**Why.** A protocol buffer enum is thirty-two bits by the language and declares no width of its own, so `int32` is true of every such enum and stated by none of them. A cell that printed it would carry a fact its evidence does not hold, read as a measurement, and a reader could not tell it apart from a width a library's own file really declares -- which is the one thing the value-type dimension is for. Saying `absent`'s words and linking the declaration tells what a file states apart from what it leaves unstated inside the cell, where the reader is, rather than in a note somewhere else.
